# Changelog

Notable user-facing changes to the SpaceMolt CLI. For agent/contributor routing details, see `AGENTS.md`.

Earlier release notes, including the full 2.10.0 detail and 2.9.0, live in git history
(`git log -- CHANGELOG.md`, `git show v2.10.0:CHANGELOG.md`) and at
https://github.com/CoinAnole/spacemolt-cli/releases.

## Unreleased

- `found_gate_site` takes `name` then `far_system` and founds one end of a jump gate at the current point of interest in lawless space. Help states the place, ManageBases, the 1235 GU limit, the 2,500,000 credit fee per end, one unfinished pair, and that the gate cannot be dismantled. The client does not check the distance or the fee. Human output prints `base_id`, `name`, `poi_id`, `system_id`, `fee_paid` including 0, `public_access` as yes or no, and `hint` when it is a non-empty string. An omitted key prints nothing. The receipt has no gate block. `set_gate_access` takes `access` and keeps the schema enum `public`, `allies`, and `faction`. Help says the operation text names `public` and `faction`. `set_toll` takes `price`. Help says 0 is free and 1000000 is the maximum. Neither command takes a station id; both act on the docked gate end. `station info` prints a Jump gate block when `gate` is an object: far system name and id, online, faction only, toll including 0, built, partner built, and partner base id when sent. While `phase` is a number it prints the phase, phase name, phases total, cycles done, cycles, labor per cycle including 0, and materials left as item id and quantity including 0. An empty or omitted materials object prints nothing. When `built` is true, entangler due and upkeep cycles covered print when those keys are numbers, including 0. An omitted `gate` prints nothing. `get_base` prints one `Jump gate:` line with the far system name or id, online as yes or no, and toll including 0 when `base.gate` is an object. An omitted `gate` prints nothing. Construction and upkeep stay on station info. An outpost without `gate` is not a gate (gameserver 0.687.0).

The header uses `repeater_count` when that count is a finite number at least as large as the list, and says when the list is shorter. An empty array and a count of 0 print nothing. An omitted or empty array prints nothing. `subscribe_observation` prints `repeaters` the same way when that array is present and non-empty. An observation preview counts `repeaters_changed` with the other changed domains and `repeaters_departed` with the other departures. An omitted key counts as none. The client does not attack them and does not add a loot table. `get_nearby` help says repeaters attack only a pilot who attacks one of them or mines at the place where they sit, and then every unit in the system turns on that pilot. Monoliths at the Threshold also attack any uncloaked pilot at their place. Repeaters also turn on pilots in their system who carry seam glass or Repeater parts (gameserver 0.687.0).

The empire destroys the hull. It is set on `empire_gift_ship` only when the donated ship was a boss flagship, and omitted otherwise. It is less than the flat amount only if the wallet hit the credit cap. An omitted `flagship_bounty` is not zero. Fleet, hull designator, npc, and petition fields stay omitted when that hull is destroyed. The CLI does not detect a flagship. The server accepts or rejects the gift (gameserver 0.657.6–0.660.2).

License prices are T1=1M, T2=5M, T3=10M, T4=20M, and T5=50M. Starter, prestige, and pirate boss flagships cannot be licensed.
